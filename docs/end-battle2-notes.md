# End battle, part 2

This is a two-minute original continuation of the dragon/golem fan story, made as twelve 10-second imported Code 3D programs. Each import is the canonical source prefixed with `const BATTLE_SCENE=N;` for N=0 through 11. It defaults to scene 1 without the prefix. The source retains the MIT credit of the supplied procedural reference and uses no external game asset.

The story progresses through an unsuccessful charge, the discovery of a healing crystal, a distraction and climb, the destruction of the crystal, coordinated attacks, a tail strike, a shared-hand rescue, a final punch and a return to the portal. Portuguese captions are rendered in the same canvas as the movie.

Motion changes address the prior feedback: world foot targets and arclength-driven walking, a separate torso pivot, bounded two-bone contacts, timing for preparation/contact/recoil/recovery, smooth quaternion flight, secondary joint motion and different actor intentions. The offline pose preflight is not evidence of WebGL rendering; the browser proof runs the actual existing studio UI and exporter.

The workflow begins in preview mode and retains sampled frames of all scenes plus one short native action clip. Full mode is enabled only after that material is reviewed; four independent runner jobs then export three clips each. Sound and final assembly are outside the studio. No secret, model request, renderer change or production deployment is part of this work.
