# A vingança dos golems

An original fictional voxel story requested by the user, with Portuguese captions inside the rendered canvas. The existing Code 3D studio imports each of four 10-second programs; an external montage joins their native video exports and adds original sound.

| Clip | Visual action |
| --- | --- |
| 1 | The articulated dragon flies over the village, breathes toward the cottage and breaks its upper structure. Blocks follow deterministic fall trajectories; two guardians react and survive. |
| 2 | Six articulated guardians converge in formation. Their leader raises an arm and a horizontal End portal activates. |
| 3 | The guardians approach the portal in order, descend through its surface and appear on the End island. |
| 4 | They march toward the dragon. The leader's arm reaches a fixed mouth contact target using two-bone IK; the dragon recoils and flies up as the battle begins. |

The village terrain, cottage and procedural texture helpers retain the MIT credit and license of Artem Novitckii's supplied Minecraft reference. The dragon, iron guardians, destruction, portal, End island, pillars, captions and story choreography are new procedural code. No external game texture, model, font or network resource is loaded by the scene. Characters follow the user's requested Minecraft-style fan story.

Every pose and release trajectory comes from absolute time. The preflight checks finite transforms and the intended punch contact; only the browser workflow verifies actual WebGL pixels and studio exports. Preview frames are retained before full exports so visual failures can be inspected. A successful report proves this imported story in the repository test instance; it does not imply autonomous Gemini authorship or production deployment.

Import `const STORY_SHOT=0;` (or 1, 2, 3) followed by `scripts/fixtures/code3d-golems-end-story.js` into `/motor-3d/codigo`. The program also defaults to clip 1 when imported alone. The existing renderer, sandbox, authentication and export implementation remain unchanged.
